Google part numbers · Bulk import

One Google part number can identify many physical items. Each item gets its own unique FabTrace tracking ID and QR.

1. Prepare your parts list

Use the template with one row per part number or row for each physical item. Set quantity to create multiple independent QR labels. Leave id blank for automatically generated IDs.

Columns: google_part_number, description, kind, project, drawing, location, handler, welds_required, quantity, id. Handler must be a registered badge ID. Duplicate Google part numbers are permitted; duplicate tracking IDs are not.

2. Review & import

Choose a CSV file to preview its rows before importing.

3. Generate & print QR labels

After import, print QR sheets in batches of 100. Each label includes the Google part number and unique FabTrace item ID. Labels point to the shared cloud record URL.

Allow print pop-ups in your browser. Print sheets at 100% scale and test QR scanning before applying labels.
